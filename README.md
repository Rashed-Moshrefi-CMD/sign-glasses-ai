# AI Smart Glasses for Sign Language Understanding

## Project Vision

This project aims to develop an AI-powered smart glasses extension capable of understanding sign language in real time using computer vision and machine learning.

The long-term vision is to create a wearable assistive system that can:
- recognize sign language,
- translate signs into text or speech,
- support real-time communication,
- and eventually integrate augmented reality assistance.

---

# Current Development Stage

The project is currently focused on building a foundational prototype using:
- webcam-based input,
- hand landmark tracking,
- gesture recognition,
- and sequence learning.
