# Technical Glossary

---

# Computer Vision

## Landmark
A detected key point in an image.

Example:
Finger joint coordinates extracted using MediaPipe.

---

## Pose Estimation
The process of estimating body or hand positions from image data.

---

## FPS (Frames Per Second)
The number of processed image frames per second.

Higher FPS improves real-time responsiveness.

---

## Tracking
The process of following an object or body part over time.

---

# Machine Learning

## Feature
Input information used by a machine learning model.

Example:
Hand landmark coordinates.

---

## Label
The correct output associated with training data.

Example:
The gesture name “hello”.

---

## Dataset
A collection of training or evaluation samples.

---

## Inference
The process of using a trained model to make predictions.

---

## Overfitting
When a model memorizes training data instead of learning generalized patterns.

---

# Sequence Learning

## Temporal Data
Data where timing and order are important.

---

## LSTM
A recurrent neural network architecture designed for sequence learning.

Useful for:
Dynamic gesture recognition.

---

## Transformer
A neural network architecture using attention mechanisms for sequence understanding.

---

# Robotics / Systems

## HRI (Human-Robot Interaction)
Research field focused on interaction between humans and robots.

---

## Edge AI
Running AI directly on local hardware devices instead of cloud servers.

---

# Software Engineering

## Repository
A version-controlled project directory managed with Git.

---

## Modular Design
Separating systems into independent components for scalability and maintainability.

---

## API
An interface allowing software components to communicate.

---

# Sign Language

## DGS
Deutsche Gebärdensprache (German Sign Language).

---

## ASL
American Sign Language.

---

## Non-Manual Markers
Facial expressions and body cues used in sign language communication.
